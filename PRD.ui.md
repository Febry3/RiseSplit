PRD Frontend: Ghost-Author (Royalty Splitter UI)Versi: 1.0Tema Desain: Modern Crypto (Dark Mode, Glassmorphism, Neon Accents)Target Tech Stack: React/Next.js, Tailwind CSS, Stellar Freighter SDK1. Visi Desain & UI/UX1.1 Estetika VisualTema: Dark Mode (Background: #0D0E12).Warna Aksen: Cyber Purple (#7C3AED) dan Emerald Green (#10B981) untuk indikator sukses.Komponen: Kartu bergaya Glassmorphism dengan blur latar belakang dan border tipis mengkilap.Tipografi: Sans-serif modern (Inter atau Sora) untuk keterbacaan tinggi.1.2 Pengalaman Pengguna (UX)Wallet-First: Aplikasi hanya bisa digunakan setelah mengoneksikan dompet (Freighter).Real-time Feedback: Notifikasi toast untuk setiap perubahan status transaksi di blockchain.Mobile Responsive: Layout yang adaptif untuk penggunaan di smartphone.2. Peta Fitur (Feature Modules)2.1 Konektivitas Dompet (Wallet Module)Fitur: Tombol "Connect Wallet" di navigasi atas.Status: Menampilkan alamat dompet yang dipersingkat (e.g., GABC...XYZ) dan saldo XLM.Integrasi: Mendukung Freighter Wallet.2.2 Inisialisasi Kontrak (Creator Studio)Formulir Dinamis: Creator bisa menambah atau menghapus baris kolaborator.Input: Alamat dompet (Address) dan Persentase (%).Auto-Calculator: Menghitung total persentase secara otomatis. Tombol "Deploy" hanya aktif jika total = 100%.BPS Converter: Frontend secara otomatis mengubah 25.5% menjadi 2550 (basis points) sebelum dikirim ke smart contract.2.3 Panel Pembayaran (Payer Interface)Fungsi: Form sederhana untuk membayar royalti.Input: Jumlah (Amount) dan Pilihan Aset (Dropdown: XLM, USDC).Summary: Menampilkan estimasi berapa yang akan diterima masing-masing kolaborator sebelum transaksi dikirim.2.4 Dashboard Pendapatan (Analytics)Stat Cards: Menampilkan "Total Revenue Processed" dan "Total Participants".Transaction Table: Daftar riwayat pembayaran masuk lengkap dengan hash transaksi dari Stellar Expert.3. Komponen UI Utama (UI Kit)KomponenDeskripsiAksiGlass CardKontainer transparan dengan border gradasi.Display DataNeon ButtonTombol dengan efek glow saat hover.Submit/DeployBPS InputField input dengan validasi angka desimal.Input LogicStatus BadgeIndikator warna (Live, Pending, Failed).Info State4. Alur Kerja Pengujian (Testing Flow)Untuk memastikan frontend berfungsi dengan baik, berikut skenario ujinya:Uji Koneksi:Klik "Connect Wallet", pastikan popup Freighter muncul.Pastikan alamat dompet muncul di UI.Uji Validasi Form:Masukkan total persentase 90%, pastikan tombol "Deploy" terkunci.Masukkan total persentase 100%, pastikan tombol "Deploy" aktif.Uji Integrasi Contract:Lakukan transaksi "Pay", pastikan muncul loading state (spinner) hingga transaksi sukses.Verifikasi munculnya notifikasi "Success" dengan link ke Stellar Explorer.Uji Responsivitas:Buka UI di ukuran layar mobile, pastikan tabel royalti dapat di-scroll atau berubah menjadi tampilan kartu.5. Aset Visual (Placeholder)Icons: Menggunakan Lucide React (Wallet, Share2, TrendingUp, ShieldCheck).Latar Belakang: Efek gradasi mesh halus di pojok layar untuk memberikan kedalaman visual.6. Metrik FrontendLoad Time: < 2 detik.Transaction Feedback: Notifikasi muncul < 500ms setelah transaksi di-submit.Error Clarity: Pesan error dari smart contract (e.g., InvalidPercentageSum) harus diterjemahkan menjadi bahasa yang mudah dipahami user di UI.
